# Modelio Extension
This script exports information of the model created in Modelio and stores it in JSON and YAML files.

The information is read from an XML file ('cwd.xml' in the "modelio" folder) exported from the class diagram and then stored in JSON and YAML files, in the "output" folder, separately for each entity (e.g., policy and device).


The script can easily be executed using the command below:
```
python main.py
```
