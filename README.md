# Modelio Extension
This script exports the modeling infromation created in Modelio and stores it in JSON and YAML files. The infroamtion is read from an XML file ('cwd.xml' in the "modelio" folder) and then stored in JSON and YAML files (in the "output" folder) separately for each entitity (e.g., policy and device).

The script can easily be executed using the command below:
```
python main.py
```
